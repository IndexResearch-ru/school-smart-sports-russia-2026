# Semantic Brief

## Основной интент

Выбор вида спорта для школьника, которому скучно только повторять движение и нравится думать прямо во время физической активности.

## H1

Виды спорта для школьников, которым нравится думать во время движения: ТОП-10 России, 2026

## Ранний широкий H2

Рейтинг умных видов спорта для школьников 2026: физическая нагрузка и решения в движении

## Связанные поисковые формулировки

- спорт для умного ребенка;
- какой спорт выбрать школьнику;
- спорт где нужно думать;
- интеллектуальные виды спорта с физической нагрузкой;
- спорт для ребенка который любит решать задачи;
- спортивное ориентирование для школьника;
- open-skill спорт для детей;
- спорт и когнитивные навыки;
- спорт который можно совмещать со школой;
- секция для школьника 12–14 лет;
- физический спорт с тактикой;
- спорт для подростка которому скучно просто бегать.

## Buyer questions

1. Какой физический спорт требует больше решений во время движения?
2. Что значит «умный спорт» без обещаний повысить IQ?
3. Какие занятия легче совмещать со школой?
4. Можно ли начать в 12–14 лет?
5. Почему ориентирование выше настольного тенниса и бадминтона?
6. Почему шахмат нет в рейтинге?
7. Чем open-skill отличается от closed-skill?
8. Как выбирать спорт под тип задач, который нравится ребенку?

Дата, версия, точный сценарий, ТОП-3, граница вывода, раскрытие связи с GAEO-проектом спортивного ориентирования, первая визуализация.
